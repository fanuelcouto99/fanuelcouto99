## Projetos em destaque

</div>

<div align="center">

### Nandu: novo SaaS com CRM e pipeline Kanban
Plataforma com CRM e pipeline Kanban para os clientes gerenciarem seus negócios.
**Stack:** NestJs · NextJs · MySQL · Prisma · Shadcn UI · Digital Ocean · HyperMeow · Webhook
**Resultado:** https://nandu.com.br

### Nandu: chat interno de suporte
Chat para o cliente falar com a equipe de suporte direto pela plataforma.
**Stack:** NestJs · NextJs · MySQL · Prisma · Shadcn UI 
**Resultado:** Widget de chat servido por CDN, usado pelos clientes para falar com o suporte direto na plataforma.

### SaaS para cantinas
Sistema SaaS para gestão de cantinas.
**Stack:** Vite · NestJs · React Native · Expo · Prisma ORM · PostgreSQL · Docker · GitHub Actions · Digital Ocean
**Resultado:** Sistema de ponto de venda e estoque para cantinas comunitárias (paróquias, escolas, festas juninas), com app para realizar as vendas e deploy automatizado via GitHub Actions.

### SaaS de controle de dízimo
Sistema SaaS para controle de dízimo em paróquias.
**Stack:** **Stack:** Vite · NestJs · Prisma ORM · PostgreSQL · Docker 
**Resultado:** Sistema de gerenciamento de dízimo em paróquias.

### App de ToDo
Aplicação de lista de tarefas.
**Stack:** Vite · React · Tailwind CSS · TypeScript · Prisma ORM · MySQL · Docker 
**Resultado:** Aplicação de lista de tarefas.

### SaaS de controle de bibliotecas
Aplicação para controle de empréstimos de livros.
**Stack:** Vite · NodeJs · Prisma ORM · PostgreSQL · Docker 
**Resultado:** Sistema de gerenciamento de bibliotecas, controlando empréstimos e devoluções de livros, estoque com detalhes de cada livro, assim como imagens de capa e descrição.
